# Technical Specification — "Mizan Dofdou" (Frog Balance)

> Audience: the implementing agent (ChatGPT Codex) and the QA reviewer (Claude).
> Read together with `docs/01-game-design.md` (product/learning rules, Arabic) and `AGENTS.md` (working rules).
> When this spec and the GDD disagree on *behaviour*, the GDD wins; on *implementation*, this spec wins.

## 1. Platform decision

| Option | Verdict | Why |
|---|---|---|
| **Web (PWA) — Phaser 3 + TypeScript + Vite** | ✅ **Chosen** | One codebase runs in every browser (Android, iOS, Windows, macOS, ChromeOS, interactive whiteboards). Installable + offline via service worker. Phaser gives touch/mouse/pen drag-and-drop, tweens, particles, audio, texture atlases and scaling out of the box. Fully testable headless with Playwright — required for the QA loop. |
| Unity WebGL | ❌ | Heavy first load (15–40 MB), weak on low-end school tablets and iOS Safari, Arabic text shaping needs plugins, hard for an agent to build/test headless. |
| Godot 4 web export | ❌ | Large wasm, no iOS Safari threads without COOP/COEP headaches, RTL support needs extra work. |
| React + SVG only | ❌ | Fine for UI, but drag physics, particles, sprite animation and audio sprites become hand-rolled. |
| Native mobile wrap | ➕ Later | Phase 7 wraps the same web build with **Capacitor** for Play Store / App Store if needed. |

**Architectural rule #1:** all game rules live in `src/core/` as pure functions with zero Phaser imports → fully unit-testable, and the scene layer only renders state and forwards input.
**Architectural rule #2:** a single source of truth per level: `LevelState` (in core). Scenes dispatch actions (`place`, `remove`, `predict`, `requestHint`) to a reducer-like `LevelController`; the view subscribes to state changes.

## 4. Core types

```ts
// src/core/types.ts
export type Side = 'left' | 'right';           // ON-SCREEN side, never reading order
export type ItemKind = 'frog' | 'number';
export interface ItemSpec { kind: ItemKind; value?: number }   // value required when kind==='number' (1..10)
export interface PlacedItem extends ItemSpec { uid: string; fixed: boolean; order: number }

export type Mode = 'count' | 'compare' | 'bond' | 'missing' | 'equation' | 'sandbox';

export interface LevelState {
  levelId: string;
  pans: Record<Side, PlacedItem[]>;
  phase: 'intro' | 'playing' | 'awaitingSettle' | 'success' | 'revealing';
  solutionsFound: string[];        // bond mode: canonical "a+b" strings (a<=b)
  prediction?: Side | 'equal';     // compare mode
  attempts: number;
  hintLevel: 0 | 1 | 2 | 3;
  hintsUsed: number;
  errors: ErrorTag[];
  startedAt: number;
}
export type ErrorTag = 'overcount' | 'undercount' | 'compareFlip' | 'equalsAsResult' | 'capacity' | 'wrongPrediction';
```

## 5. Balance logic (src/core/balance.ts) — must match GDD §7 exactly

```ts
export const weightOf = (i: ItemSpec) => i.kind === 'frog' ? 1 : i.value!;
export const panWeight = (items: ItemSpec[]) => items.reduce((s, i) => s + weightOf(i), 0);
export const diff = (L: ItemSpec[], R: ItemSpec[]) => panWeight(R) - panWeight(L);
export function beamAngle(d: number, c = CONFIG.beam): number {
  if (d === 0) return 0;
  // positive angle = right side DOWN (clockwise in screen space)
  return Math.sign(d) * Math.min(c.maxAngle, c.base + c.step * (Math.abs(d) - 1));
}
export function canPlace(pan: ItemSpec[], item: ItemSpec, cap = CONFIG.capacity): boolean // ≤3 numbers, ≤10 frogs; mixed pan: ≤2 numbers and ≤6 frogs
```
CONFIG.beam = `{ base: 6, step: 3, maxAngle: 20 }` (degrees).
Settle rule: a level goal is evaluated only after the pan state has been unchanged **and** no item is being dragged for `CONFIG.settleMs = 1000`.

Spring: semi-implicit Euler, stiffness 120, damping 14, mass 1, run in `update()`; settles in < 700 ms. With reduced motion: single 200 ms tween, no overshoot.

## 6. Level schema (content/levels.json) — enforced by zod

```ts
const Item = z.object({ kind: z.enum(['frog','number']), value: z.number().int().min(1).max(10).optional() })
  .refine(i => i.kind === 'frog' ? i.value === undefined : i.value !== undefined);

const Level = z.object({
  id: z.string().regex(/^(w[1-6]-l[1-8]|practice-\d+)$/),   // authored file must use wX-lY only (see LevelsFile refine)
  world: z.number().int().min(1).max(6),
  index: z.number().int().min(1).max(8),
  mode: z.enum(['count','compare','bond','missing','equation']),
  fixed: z.object({ left: z.array(Item), right: z.array(Item) }),
  workPan: z.enum(['left','right']).nullable(),          // null for compare
  tray: z.object({ frogs: z.boolean(), numbers: z.array(z.number().int().min(1).max(10)) }),
  childLimits: z.object({ maxNumbers: z.number().int().min(0).max(3), maxFrogs: z.number().int().min(0).max(10) }),
  goal: z.discriminatedUnion('type', [
    z.object({ type: z.literal('balance') }),
    z.object({ type: z.literal('predict') }),
    z.object({ type: z.literal('balanceMulti'), requiredSolutions: z.number().int().min(1).max(4),
               childNumbersExactly: z.number().int().min(1).max(2) }),
  ]),
  showEquation: z.boolean(),
  guideArrow: z.boolean(),
  vo: z.object({ intro: z.string(), success: z.string().optional() }),   // keys into strings.ar.json / audio files
});
export const LevelsFile = z.object({ version: z.literal(1), levels: z.array(Level).length(48) })
  .refine(f => f.levels.every(l => l.id === `w${l.world}-l${l.index}`), 'authored ids must be w<world>-l<index>')
  .refine(f => new Set(f.levels.map(l => l.id)).size === 48, 'duplicate level ids');
// Practice-mode levels produced by generator.ts use id `practice-<n>` and the same Level schema.
```

Semantics:
- `fixed` items are placed at level start, show a lock badge and cannot be dragged.
- The child may only drop on `workPan` (the other pan is a non-target; drops there bounce back). In `compare`, nothing is draggable.
- `tray.numbers` are **sources**: dragging a tile spawns a copy; the source stays (infinite supply). Same for the frog pile.
- `balance`: success when settled and `diff === 0` and child added ≥ 1 item.
- `balanceMulti` (bond): success-per-solution when settled, `diff === 0`, and the child placed exactly `childNumbersExactly` number tiles and no frogs. The canonical solution string = all work-pan numbers (fixed + child) sorted ascending joined by `+`. A *new* canonical string is recorded, a mini celebration plays, the child items fly back to the tray, and the level completes when `solutionsFound.length === requiredSolutions`. A repeated solution plays "لقيتها قبل كده! جرّب طريقة تانية".
- `predict` (compare): UI shows three big buttons — left pan glow, right pan glow, "=" button. On tap: store prediction, unlock beam, animate, evaluate. Correct → success. Wrong → `wrongPrediction` error, reveal explanation VO, then load a *sibling* question (generated with the generator, same difference band) — the level completes after one correct prediction.

### Solvability check (unit-tested for all 48 levels)
- `balance`: let `need = weight(otherPan fixed) − weight(workPan fixed)`; must be `> 0`, and there must exist a combination of ≤ `maxFrogs` frogs (if `tray.frogs`) and ≤ `maxNumbers` tray numbers whose weight = `need`, respecting `canPlace` capacity.
- `balanceMulti`: the number of distinct canonical solutions reachable with tray numbers must be ≥ `requiredSolutions`.
- `predict`: always solvable; additionally assert `fixed.left` and `fixed.right` each contain ≥ 1 item.

## 7. Error classification (core/scoring.ts)
Evaluate on each settle where the goal is not met:
- `overcount`: count mode, work pan heavier by exactly 1 or 2 (child overshot).
- `undercount`: count mode, lighter and the child has been idle ≥ idle threshold.
- `equalsAsResult`: equation mode, work pan weight equals the *sum of all fixed items on the other pan + the fixed items on the work pan* (child put the "answer" of the other side).
- `capacity`: rejected drop due to capacity.
`attempts` increments on every settle that does not meet the goal **after** a change.
Stars: 3 if `hintsUsed===0`, 2 if max hint level reached ≤ 2, else 1.

## 8. Progress & storage (core/progress.ts + services/storage.ts)
```ts
interface SaveV1 {
  version: 1;
  settings: { numerals: 'arabic-indic'|'western'; voCount: boolean; music: number; sfx: number; vo: number;

                           errors: Partial<Record<ErrorTag, number>>; lastPlayed: number }>;

```
- Key: `frogBalance.save`. All reads/writes wrapped in try/catch; on failure fall back to in-memory and never crash.
- Unlock rule: level n+1 unlocks when level n has ≥ 1 star; world w+1 unlocks when world w has ≥ 6 levels with ≥ 1 star.
- `migrate(raw): SaveV1` handles missing/corrupt data (returns defaults).

## 10. Layout & scaling
- Phaser `Scale.RESIZE`; a `LayoutManager` chooses `landscape` (w ≥ h) or `portrait`, computes a uniform `uiScale = min(w/1280, h/720)` (landscape) or `min(w/720, h/1280)` (portrait), and repositions every object from an anchor map in `layout.ts` on `resize`.
- Minimum supported viewport: 360×640. Max: 3840×2160.
- Safe-area insets respected (iOS notch) via CSS `env(safe-area-inset-*)` padding on the canvas parent.
- Touch targets ≥ 64 design px. Drop zones = pan bounds × 1.5.
- Disable browser gestures on the canvas: `touch-action: none`, prevent pinch-zoom, prevent context menu, prevent text selection.

## 11. Arabic / RTL
- `index.html`: `lang="ar" dir="rtl"`.
- Phaser Text objects: set `rtl: true` for Arabic strings, font family `'Baloo Bhaijaan 2'`. Wait for `document.fonts.load('700 32px "Baloo Bhaijaan 2"')` in BootScene before creating text (prevents fallback-font flash and wrong metrics).
- Digits: `numerals.ts → formatNumber(n, system)`; Arabic-Indic map `٠١٢٣٤٥٦٧٨٩`. Number tile textures render the digit through this function, so switching the setting re-renders tiles.
- EquationBar: three groups positioned above left pan, center, right pan (GDD §7.3). Inside a group, terms in placement order, laid out right-to-left when RTL; `؟` for the missing slot.

## 12. Audio
- Format: **mp3** (universally supported) mono 44.1 kHz, VO normalised to −16 LUFS, SFX −20 LUFS.
- Channels: music (loop), sfx, vo. VO ducks music to 30 %. VO queue never overlaps; a new VO with `priority: 'interrupt'` stops the current one.
- iOS/Android autoplay: audio unlocked on the first pointerdown on the Title screen ("▶" button).
- Until real VO exists: `AudioManager` falls back to `speechSynthesis` with `lang='ar-EG'` if available, else silent + subtitle toast in dev. Missing files must never throw.
- Counting VO: files `vo/count_01.mp3 … count_20.mp3`.

## 13. Placeholder art (Phase 0–4)
`placeholderArt.ts` must generate, with Phaser Graphics + `generateTexture`, every texture key listed in `docs/05-assets.md` §1 at the right size, so the game is fully playable before final art arrives. Final art later replaces keys 1:1 through `atlas.json` with no code change.

## 14. Performance budgets
- 60 fps on a mid Android tablet (e.g. Samsung Tab A8) and iPad 9th gen; never below 30 fps on a 2019 budget Android phone.
- Max 1 texture atlas ≤ 2048×2048 for gameplay; backgrounds as separate compressed WebP/PNG ≤ 300 KB each.
- No allocation in `update()` loops; object pools for frogs (max 40 live) and particles.
- First load (gzipped JS + atlas + title music) ≤ 8 MB; VO streamed per world.
